# **App Name**: Dheerendra Singh Portfolio

## Core Features:

- Home Page: Display a dynamic, SEO-optimized landing page featuring a hero section with Dheerendra Singh's title, tagline, and profile information.
- Dynamic Gallery: Showcase an admin-manageable gallery of images and videos with filtering options.
- Achievement Timeline: Display achievements, awards, and recognitions in a dynamic and visually appealing timeline or card format.
- About Section: Feature an 'About' section with rich content, biography, profile picture, and key highlights.
- Contact Form: Include a contact form for visitors to send messages directly, with admin-editable contact information.
- Testimonials: Display audience testimonials with names, photos, messages, and optional video/audio feedback, all manageable via the admin panel.
- Course Listing: Showcase a dynamic list of courses with titles, descriptions, thumbnails, prices, categories, and external/internal links, all editable in the admin panel.

## Style Guidelines:

- Primary color: Deep blue (#224270) to convey trust and professionalism.
- Background color: Light gray (#F0F4F8) to provide a clean and modern backdrop.
- Accent color: Gold (#FFD700) to highlight achievements and important information.
- Headline font: 'Playfair', a modern serif, for headlines.
- Body font: 'PT Sans', a humanist sans-serif, for body text.
- Use professional and minimalist icons to represent different sections and categories.
- Employ a clean and structured layout to enhance readability and navigation.
- Incorporate subtle animations on scroll or hover to create a polished user experience.
